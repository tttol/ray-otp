# Icon sources

The SVG files in this directory are original, minimal geometric marks created for `ray-otp`.

- `aws.svg`: original cloud mark with an AWS label; no AWS artwork was copied.
- `microsoft.svg`: original four-square mark with a Microsoft label; no Microsoft artwork was copied.
- `generic.svg`: original key mark created for this extension.

These files are distributed under the repository's MIT license. They are visual labels only and are not affiliated with or endorsed by AWS or Microsoft.
